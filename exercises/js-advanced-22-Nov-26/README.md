# Задача: Система за резервация на места в кино

## Начални файлове

- `index.html` — готова структура на страницата.
- `style.css` — готови стилове, включително класове за състоянията на местата.
- `script.js` — празен файл за вашето решение.

Отворете `index.html` в браузър. Първоначално схемата на местата ще бъде празна — тя трябва да се генерира с JavaScript.

## Задача 1: Генериране на места

1. Генерирайте **4 реда с по 8 места** в контейнера `#seat-map`.
2. Редовете са означени с **A, B, C и D**; местата във всеки ред са номерирани от **1 до 8**.
3. Всяко място има уникален идентификатор, например `A1`, `B3` или `D8`.
4. Следните места са предварително заети: **A2, A6, B5, C3, D7**.
5. Използвайте DOM методи за създаването на елементите.

## Задача 2: Избор на места

1. Клик върху свободно място го маркира като избрано.
2. Повторен клик премахва избора.
3. Избраните места трябва да използват CSS класа `.seat--selected`.
4. Заетите места използват `.seat--occupied` и не могат да бъдат избирани.
5. Свободните места използват `.seat--available`.

## Задача 3: Цена и брой места

1. Едно място струва **6€.**
2. Актуализирайте `#selected-count` и `#total-price` при всяка промяна на избора.
3. При липса на избрани места показвайте `0` и `0€.`.

## Задача 4: Списък с избрани места

1. Показвайте избраните места в `#selected-seats`.
2. Подреждайте ги по ред (A–D), а след това по номер (1–8).
3. Ако няма избрани места, показвайте съобщението „Няма избрани места“ в `#empty-selection`.
4. Обновявайте списъка при всяка промяна.

## Задача 5: Потвърждаване на резервация

1. При натискане на `#reserve-btn` проверете дали има избрани места.
2. Ако няма, покажете подходящо съобщение в `#status-message`.
3. Ако има, превърнете всички избрани места в заети.
4. Изчистете текущия избор и актуализирайте броя, цената и списъка.
5. Покажете съобщение с идентификаторите на успешно резервираните места.

## Задача 6: Изчистване на избора

1. При натискане на `#clear-btn` премахнете всички текущи селекции.
2. Вече заетите места остават заети.
3. Обновете цената, броя и списъка.

## Подсказки за структурата

| Елемент | Предназначение |
| --- | --- |
| `#seat-map` | Контейнер за динамично генерираните редове и места |
| `#selected-count` | Брой избрани места |
| `#total-price` | Обща цена |
| `#selected-seats` | Списък с избраните места |
| `#empty-selection` | Съобщение при празен избор |
| `#reserve-btn` | Бутон за резервация |
| `#clear-btn` | Бутон за изчистване |
| `#status-message` | Съобщение за успех или грешка |
